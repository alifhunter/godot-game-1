# Test Log

Use this folder for historical test reports, smoke-test summaries, simulation audits, and release verification notes.

## Naming

Use date-first filenames so entries sort chronologically:

`YYYY-MM-DD_scope.md`

Examples:

- `2026-06-13_30_day_full_test.md`
- `2026-06-13_225_day_market_audit.md`
- `2026-06-13_steam_release_smoke.md`

## Entry Format

Each test-log entry should include:

- Date and tester
- Branch, build, or commit context
- Test scope
- Commands or manual flow used
- Pass/fail summary
- Failures and suspected cause
- Performance notes
- Follow-up actions
