# News Content Editor

Dev-only local editor for `News` content. It uses only Python stdlib and is not part of the player build.

## Run

From the project root:

```bash
python tools/news_editor/server.py
```

Open:

```text
http://127.0.0.1:8766
```

## Workflow

- `Load` reads `tools/news_editor/news_source.json`.
- If the source has no catalog yet, the editor imports `data/news/news_feed_data.json`.
- `Save Source` saves editable source data only.
- `Validate` checks outlet ids, voice references, author outlet ids, phrase pools, body-slot fallbacks, voice template fallbacks, and asset paths.
- `Export Runtime JSON` writes `data/news/news_feed_data.json`.
- Uploaded outlet logos or author portraits are copied into `assets/news/` and stored as `res://assets/news/...`.

## Edited Data

The tool edits the template catalog used by `systems/NewsFeedSystem.gd`:

- outlets and intel levels
- author metadata and byline/contact lead hints
- progress labels
- reference signal pools
- driver phrase pools
- watch phrase pools
- article body slot templates
- outlet voice profiles

It does not edit generated save-game article archives. Runtime articles are still generated by Godot from market/event state plus these template pools.

## CLI Checks

```bash
python tools/news_editor/server.py --validate
python tools/news_editor/server.py --export --dry-run
```

Use `--export` without `--dry-run` to update the runtime News JSON from the source.
